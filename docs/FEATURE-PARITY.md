# 웹·앱 기능 대응표

passQL은 웹(React, `client/`)과 앱(Flutter, `app/`)을 따로 유지한다. 둘 다 같은 Spring API를 쓰고
같은 Firebase 프로젝트(`passql`)로 로그인하므로, 같은 Google 계정이면 같은 회원·같은 학습 기록이다.

**원칙** (#433): 화면을 1:1로 맞추지 않는다. 아래 "핵심" 기능은 양쪽에 반드시 있어야 하고,
"플랫폼별"은 달라도 된다. 새 기능을 넣을 때 이 표를 함께 고친다.

- 웹: 검색 유입·첫 체험 (설치 없이 바로 문제 풀이)
- 앱: 매일 쓰는 학습 도구 (푸시 등 앱 고유 기능은 앱에만)

## 플랫폼별 (달라도 됨)

| 기능 | 웹 | 앱 |
|---|---|---|
| 홈 구성 | 시험 일정·데일리·히트맵·준비도 카드 | 앱 홈 |
| 데일리 챌린지 화면 | ✅ | ❌ |
| 챕터·토픽 탐색 | 카테고리 카드 | 챕터·토픽 목록 |
| 마이페이지 | 별도 페이지 | 설정 탭에 통합 |
| 앱 출시 안내 | ✅ 스토어 링크 설정 시에만 | — |

## 앱 출시 안내 켜는 법 (웹)

관리자 > 앱 설정 > `STORE` 카테고리의 `store.android_url`, `store.ios_url` 에 https 링크를 넣으면
웹 홈 상단 배너와 설정의 "앱 받기" 항목이 바로 나타난다. 비우면 다시 숨겨진다 (배포 불필요).
