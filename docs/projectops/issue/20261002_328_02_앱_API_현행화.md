📝 현재 문제점
---

앱의 API 정의가 구버전 서버 기준이라 현재 서버와 맞지 않는다.
- `memberUuid` 쿼리/헤더를 여러 API에서 직접 넘기고 있다.
- 추천 문제는 앱이 GET, 웹은 POST(`size`, `excludeQuestionUuids`)를 쓴다. 웹 쪽 이유는 #291(헤더 한도 초과 400).
- 진도 AI 코멘트 파라미터명이 서버(`sessionUuid`)와 맞는지 확인이 필요하다.

🛠️ 해결 방안 / 제안 기능
---

- 인증은 토큰 헤더로 통일하고 각 API 시그니처에서 `memberUuid` 인자를 제거한다.
- 추천 문제를 POST 방식으로 맞춘다.
- 서버 컨트롤러 기준으로 엔드포인트, 파라미터, 응답 모델을 전수 대조한다.
