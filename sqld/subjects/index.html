SQLD 과목·출제 범위

SQLD는 1과목 데이터 모델링의 이해와 2과목 SQL 기본 및 활용, 두 과목으로 치러요. 과목별 문항 수와 주제 9개를 정리했어요.

데이터 모델링

엔터티·속성·관계·식별자를 구분하고, 정규화가 데이터 정합성과 SQL에 주는 영향을 이해해요.

2과목 · SQL 기본 및 활용

40문항 · 주제 8개

SELECT 기본

SELECT·FROM·WHERE·ORDER BY 기본 문법, 연산자 우선순위, NULL 비교와 정렬 순서.

DDL / DML / TCL

테이블을 만들고 바꾸는 DDL, 데이터를 넣고 고치는 DML, COMMIT·ROLLBACK 트랜잭션 제어.

SQL 함수

문자·숫자·날짜 함수와 형 변환, NVL·COALESCE·CASE 같은 NULL·조건 처리 함수.

JOIN

INNER·OUTER·CROSS·NATURAL JOIN과 조인 조건, 표준(ANSI) 조인 문법.

서브쿼리

WHERE·FROM·SELECT 절 서브쿼리, 단일 행·다중 행 비교, IN·EXISTS, 인라인 뷰.

그룹함수 / 집계

GROUP BY·HAVING, 집계 함수의 NULL 처리, ROLLUP·CUBE·GROUPING SETS.

윈도우 함수

RANK·DENSE_RANK·ROW_NUMBER 순위, 누적 합계, LAG·LEAD 같은 행 순서 함수.

계층 / PIVOT

START WITH·CONNECT BY 계층 쿼리와 PIVOT·UNPIVOT 행열 전환.

SQLD 과목 자주 묻는 질문

SQLD 시험은 어떻게 구성되나요?expand_more

필기 시험만 있습니다. 데이터 모델링의 이해 10문항, SQL 기본 및 활용 40문항, 모두 50문항 객관식이며 시험 시간은 90분입니다.

SQLD는 어려운가요?expand_more

50문항 중 40문항이 SQL이고, 짧은 쿼리의 결과 행 수나 값을 직접 따라가 계산하는 문제가 많습니다. SQL을 처음 본다면 문법을 외우기보다 결과를 확인하며 익히는 시간이 필요합니다.

SQLD와 SQLP는 무엇이 다른가요?expand_more

SQLP(SQL 전문가)는 상위 자격으로 필기 3과목에 실기가 더해지고, 응시 자격 요건이 있습니다. SQLD 범위인 데이터 모델링과 SQL 기본 및 활용은 SQLP 필기와 겹칩니다.
