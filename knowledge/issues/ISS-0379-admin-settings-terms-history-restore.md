# ISS-0379: 관리자 설정·약관에 변경 이력·복원·검증이 없음

GitHub #624 (원본: 이슈 본문).

## 증상
설정: 키 검색, 값 유형별 검증·입력 컨트롤, 변경 이력·롤백이 없다. 약관: 이전 버전 diff와 복원, 미리보기가 없다.

## 재현 조건
해당 없음 (기능 이슈).

## 조사 기록
- 2026-10-24: 관리자 화면만으로 운영(DB 직접 조회 없이)하기 위한 관리자 개선 묶음(GitHub #611~#631) 중 하나로 등록. 공통 조건: 관리자 변경 작업은 기존 `AdminAuditLogService`로 감사 로그, 서버 API 변경 시 `api-contract/openapi.json` 갱신까지 한 커밋.
- 작업 범위: 설정 키 검색, 토글·숫자 범위 입력, 변경 이력과 롤백, 약관 버전 diff·복원 버튼·마크다운 미리보기.
- 2026-10-24: GitHub #611 통합 구현 보고서(PR #634) 결과 — 일부: 설정 검색·입력 컨트롤·이력·롤백, 약관 diff·복원은 들어갔고 키별 값 범위 검증은 없음. 남은 일: 설정 키별 값 범위 정의. 이슈는 열려 있다(라벨 `작업전`).

## 근본 원인
기능 이슈. 해당 기능이 없었다(원본 「현재 문제점」 기준). 코드상 원인은 원본에 적혀 있지 않다.
