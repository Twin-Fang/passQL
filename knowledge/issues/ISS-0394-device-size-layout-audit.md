# ISS-0394: 기기 크기별 화면·폰트·UX 문제 점검

GitHub #646 (원본: 이슈 본문과 점검 결과 댓글 2개).

## 증상
기기 크기별로 화면 깨짐, 글자 크기, UX 문제가 없는지 앱 전체에서 확인한 기록이 없다. 작은 폰(320폭)·일반 폰·큰 폰·태블릿, 큰 글자(접근성) 설정에서 어떻게 보이는지 모른다.

## 재현 조건
해당 없음 (점검 이슈). 2차 점검에서 찾은 줄바꿈 문제: iOS 6.3" 시뮬레이터, 다크, 글자 크기 최대 `accessibility-extra-extra-extra-large`.

## 조사 기록
- 2026-10-25: 1차 — 위젯 테스트 기반 레이아웃 점검(임시 파일, 레포에 올리지 않음). 홈·문제 목록·통계, 화면 5종(320x568 · 375x667 · 393x852 · 440x956 · 768x1024) × 글자 배율 3종(1.0 · 1.4 · 2.0, 앱 상한 1.4 적용) × 라이트·다크 = 90개. 오버플로우·렌더 예외 0건.
- 2026-10-25: 1차에서 못 한 것 — 시뮬레이터·에뮬레이터 실캡처(가용 메모리 약 5.4GB가 새 기기 부팅 기준 약 7.2GB에 못 미쳐 대여가 막힘, 사용자 승인 없이 넘기지 않음).
- 2026-10-25: 2차 — iOS 시뮬레이터 실캡처(홈·문제 목록·문제 풀이·내 프로필·설정). 낮음 2건 미수정: 문제 목록 `풀이 모드` 행 부제목 "검증된 선택지를 먼저 써 / 요", 홈 출제 경향 카드 제목 "NULL 함 / 정"이 단어 중간에서 줄바뀜. 정보 1건: 홈 공지 배너 한 줄 말줄임(의도된 동작). 잘림·겹침·가로 스크롤·하단 탭 가림은 5화면 모두 없음.
- 2026-10-25: 미수정 이유 — `PassqlKeepAllText`(단어 중간 줄바꿈 방지)로 바꾸면 해결되지만 이 위젯이 글자 사이에 보이지 않는 연결 문자를 넣어 `find.text(...)`를 쓰는 기존 테스트 17개가 실패한다. `findTextContainingIgnoringWordJoiners` 헬퍼로 17곳을 같이 고쳐야 해 되돌림. 후속 이슈로 `PassqlListRow` 줄바꿈과 테스트 정리를 한 번에 하길 권장(대상: `PassqlListRow` 제목·부제목, `exam_trend_pattern_card.dart` 제목·설명).
- 2026-10-25: 확인 못 한 것 — 작은 폰(SE급) 실기기·에뮬레이터, iPad, Android 실캡처, 터치 영역 44pt 실측(설정 우측 상단 톱니 아이콘), 광고 배너와 하단 탭 겹침, 라이트 모드 실캡처. 이슈는 열려 있다(라벨 `작업전`).

## 근본 원인
점검 이슈. 확인된 줄바꿈 문제는 해당 텍스트가 단어 중간 줄바꿈 방지 위젯(`PassqlKeepAllText`)을 쓰지 않기 때문(2차 댓글 기준).
