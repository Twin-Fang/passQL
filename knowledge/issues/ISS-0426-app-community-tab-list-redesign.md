# ISS-0426: 앱 토론 탭 첫 화면·의견 화면을 게시판 목록·댓글 모양으로 개편

GitHub #741 (원본: 이슈 본문과 댓글. 수집 시점 열린 이슈, 라벨 `작업중`).

## 증상
앱 토론 탭을 홈(GitHub #701), 문제 탭(GitHub #726)과 같은 톤으로 맞추는 디자인 요청. 서버·API 계약 변경 없이 지금 서버 API가 주는 값만 쓴다.

현재 문제점(이슈 본문 기준):
- 첫 화면: 큰 제목 「토론」 아래 보기 4개(뜨는 토론, 최신 경향, 내가 푼 문제, 내 의견)가 칩 줄이고, 문제가 둥근 카드 목록으로 나온다.
- 의견 화면: 위쪽이 카드와 「문제 다시 보기」 줄, 정렬은 칩 2개, 하단은 「의견 쓰기」 버튼.

요청 방향: 첫 화면은 에브리타임 게시판 목록처럼(세그먼트, 끝까지 닿는 줄, 주제 아이콘 타일, 지문 2줄, `3분 전 · 의견 12`), 의견 화면은 게시글 + 댓글처럼(문제 블록, 「최신순 ⇅」 토글, 닉네임 첫 글자 아바타, 3줄 넘으면 「더 보기」, 하단 입력줄 「헷갈린 점이나 풀이 팁을 남겨 보세요」).

이번에 하지 않는 것(서버 작업 필요 등): 첫 화면 대표 의견 미리보기, 의견 화면 전체 의견 수, 대댓글·스크랩, 토론 화면 광고(`app/CLAUDE.md` 광고 자리 4종·`ad_placement_rules_test.dart`에 토론 화면이 없음), 홈 「오늘의 토론」 카드(`community_daily_discussion_card.dart`), 웹(`client/`).

## 재현 조건
해당 없음 (디자인 개편).

## 조사 기록
- 2026-10-28: 이슈 등록.
- 2026-10-28: 담당자 리포트 댓글(`## 개요` 형식). 첫 화면을 `PassqlSegmentedControl` 4칸 + 목록 줄로, 의견 화면을 문제 블록 > 정렬 줄 > 댓글형 의견 > 하단 입력줄(`community_compose_bar.dart` 신규)로 바꿨다고 적음. 의견 화면 주제 아이콘 타일은 문제 상세 응답에 주제 코드가 없어 넣지 않았다. 부수로 탭 화면 빈·오류 안내 쏠림을 `PassqlSliverFillStatus`로 고침. 검증: 분석 무이슈, 전체 테스트 68개 통과, 시뮬레이터 라이트·다크 정지 화면. 직접 눌러 보는 확인(정렬 토글, 좋아요, 더 보기, 무한 스크롤, 입력줄 > 작성 시트, 메뉴 시트, 실제 키보드 닫기)은 하지 못했다고 적음.
- 리포트의 남은 주의: 정답·오답 줄은 작성자가 풀이 공개(`includeSolveSnapshot`)를 켠 글에만 붙음(내 글에 항상 보이려면 서버 수정 필요), 좋아요 빨강이 오답 빨강과 같은 토큰(`wrong`), 의견 화면 시각은 `MM/dd HH:mm`이고 첫 화면은 "N분 전"으로 화면마다 다름.
- 수집 시점에 이슈는 열려 있다. 닫힘·배포 여부는 원본에 없다.
