# ISS-0343: 오늘의 세트 문제 품질 점검 — 동일 보기, 해설 오류, 보기 순서

GitHub #555 (원본: 이슈 본문과 댓글).

## 증상
2026-10-20 오늘의 세트 10문제를 직접 풀며 확인한 데이터 품질 결함:
- 6번: 보기 B와 C가 완전히 같은 결과 표(홍길동 3000, 김영희 5000, 이철수 4000).
- 3번: AI 해설이 문제에 없는 "기준 SQL"을 근거로 들고, 정답 C가 "A.ID=2 행만 반환"이라 설명하지만 실제 실행 결과는 2행(ID 2, 3).
- 1번: GROUP BY 결과로 "결과 없음 · 0행" 보기 — 데이터가 4행 있으면 불가능해 바로 소거되는 약한 오답.
- 8번: 숫자 보기 순서가 1, 3, 4, 2로 섞임.

## 재현 조건
2026-10-20 오늘의 세트 1·3·6·8번.

## 조사 기록
- 2026-10-20 제안: 보기 결과 중복 검사, 해설에 실제 샌드박스 실행 결과 근거, 결과형 오답은 같은 데이터에서 나올 수 있는 결과로 제한, 숫자 보기 오름차순, 공개 문제 일괄 점검(GitHub #504와 연계).
- 2026-10-21: 커밋 bd8e564e, c53f1b12로 처리. 공개 문제 전수 점검은 GitHub #565로 남김.

## 근본 원인
리포트: "해설 사실 오류의 원인은 모델이 결과를 머릿속으로 추론했기 때문이다." 보기 중복은 데이터가 생기는 경로(고정 보기 가져오기, AI 보기 생성, 하네스 양산)에 중복 차단이 없었다.
