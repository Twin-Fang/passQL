# ISS-0382: 관리자 토론 게시글·신고에 일괄 처리·처리 사유·제재 연계·통계가 없음

GitHub #627 (원본: 이슈 본문).

## 증상
토론 게시글·신고 모두 일괄 처리가 없고 글 단위 처리뿐이다(`community-posts.html:46-54`). 처리 사유 기록, 작성자 제재 연계, 처리 통계가 없다.

## 재현 조건
해당 없음 (기능 이슈).

## 조사 기록
- 2026-10-24: 관리자 화면만으로 운영(DB 직접 조회 없이)하기 위한 관리자 개선 묶음(GitHub #611~#631) 중 하나로 등록. 공통 조건: 관리자 변경 작업은 기존 `AdminAuditLogService`로 감사 로그, 서버 API 변경 시 `api-contract/openapi.json` 갱신까지 한 커밋.
- 작업 범위: 게시글 일괄 숨김·삭제·작성자·기간·신고 수 필터와 정렬, 신고 일괄 기각·숨김·건별 처리·신고 많은 순 정렬·사유 필터, 처리 사유 메모와 이력·작성자·신고자 제재 바로가기, 처리 건수·평균 처리 시간 통계·글 상세와 댓글 관리.
- 2026-10-24: GitHub #611 통합 구현 보고서(PR #634) 결과 — 일부: 토론 글·신고 일괄 처리, 필터, 처리 이력, 통계는 들어갔고 신고자 제재 바로가기와 댓글 관리는 없음. 남은 일: 신고자 제재 바로가기(식별 정보 노출 정책 결정 필요), 댓글 엔티티 도입 후 댓글 관리. 이슈는 열려 있다(라벨 `작업전`).

## 근본 원인
기능 이슈. 해당 기능이 없었다(원본 「현재 문제점」 기준). 코드상 원인은 원본에 적혀 있지 않다.
