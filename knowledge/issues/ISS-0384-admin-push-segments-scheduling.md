# ISS-0384: 관리자 푸시 대상이 전체/회원 지정뿐이고 예약·템플릿·테스트 발송·통계가 없음

GitHub #629 (원본: 이슈 본문; 완료 내용은 GitHub #611 통합 리포트 댓글).

## 증상
푸시 대상이 전체/회원 지정 둘뿐이다(`PushAudience.java:7-8`). 예약 발송, 템플릿 저장, 테스트 발송이 없다. 이력 필터와 실패 기기 상세, 열람률 통계가 없다.

## 재현 조건
해당 없음 (기능 이슈).

## 조사 기록
- 2026-10-24: 관리자 화면만으로 운영(DB 직접 조회 없이)하기 위한 관리자 개선 묶음(GitHub #611~#631) 중 하나로 등록. 공통 조건: 관리자 변경 작업은 기존 `AdminAuditLogService`로 감사 로그, 서버 API 변경 시 `api-contract/openapi.json` 갱신까지 한 커밋.
- 작업 범위: 세그먼트 대상(Pro/무료, 미접속자, 플랫폼별), 예약 발송·템플릿 저장·테스트 발송, 이력 필터·검색·실패 기기 목록·열람률 통계.
- 2026-10-24: GitHub #611 통합 구현 보고서(PR #634, 운영 배포) 결과 — 푸시 세그먼트, 예약 발송, 템플릿, 테스트 발송, 통계 완료. 이 이슈 자체에는 완료 댓글이 없어 완료 리포트는 #611 쪽에 있다.
- 미실행 검증(#611 리포트): 예약 푸시 스케줄러 실동작은 확인하지 못했다.

## 근본 원인
기능 이슈. 해당 기능이 없었다(원본 「현재 문제점」 기준). 코드상 원인은 원본에 적혀 있지 않다.
