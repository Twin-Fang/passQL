# ISS-0309: 주제 체계 보강과 실전 난이도 문제 은행 확장

GitHub #504 (원본: 이슈 본문과 댓글).

취소로 닫힘: "이후 명세가 많이 바뀌어 이 이슈 내용은 지금 방향과 맞지 않아 정리합니다. 이미 반영된 부분은 다른 이슈(무료/프로 플랜 #576, 광고 #506·#522 등)로 들어갔고, 다시 필요한 기능은 지금 명세에 맞춰 새 이슈로 엽니다." (2026-10-26)

## 증상
- SQLD 난이도는 58회(2025.8)부터 크게 올랐고 회차마다 오르내린다. 어려운 회차는 두 선택지 사이에서 헷갈리는 문제가 많다. 근거는 GitHub #500 댓글의 카페 조사 보고서(56~62회 후기 47개).
- 현재 주제 9개에 공식 범위인 집합 연산자, 정규 표현식, DCL, TOP-N, PIVOT/UNPIVOT이 따로 없다.
- 1과목(데이터 모델링)이 하나로 묶여 세부 약점을 볼 수 없다.
- NULL·공집합 함정은 여러 주제에 걸쳐 교차 태그가 필요하다.
- 문제 유형과 난이도 단계가 실제 출제 비중을 따르지 않는다.

제안(실행 안 됨): 공식 범위 기준 주제 추가와 교차 태그, 2과목 유형 비율(실행 결과 맞히기 40~45% 등), 난이도 4단계(L1 20%, L2 40%, L3 30%, L4 10%), 주제·태그 마이그레이션(V0_10_50 대역), 복원 문제 원문은 저작권 때문에 옮기지 않음.
