# ISS-0373: 관리자 개념 문서·시험 일정·선택지 세트 화면의 미리보기·일괄 처리·필터 부족

GitHub #618 (원본: 이슈 본문; 완료 내용은 GitHub #611 통합 리포트 댓글).

## 증상
개념 문서: 마크다운 미리보기·검색·정렬이 없다. 시험 일정: 지난 일정 정리와 일괄 등록이 없다. 선택지 세트: 출처·상태·문제 필터와 일괄 비활성화·승격이 없다.

## 재현 조건
해당 없음 (기능 이슈).

## 조사 기록
- 2026-10-24: 관리자 화면만으로 운영(DB 직접 조회 없이)하기 위한 관리자 개선 묶음(GitHub #611~#631) 중 하나로 등록. 공통 조건: 관리자 변경 작업은 기존 `AdminAuditLogService`로 감사 로그, 서버 API 변경 시 `api-contract/openapi.json` 갱신까지 한 커밋.
- 작업 범위: 개념 문서 미리보기·검색·정렬·순서 변경, 시험 일정 지난 일정 정리·CSV 일괄 등록, 선택지 세트 필터·일괄 처리·생성 실패율 통계.
- 2026-10-24: GitHub #611 통합 구현 보고서(PR #634, 운영 배포) 결과 — 개념 문서·시험 일정·선택지 세트 보강 완료(문서 순서 대신 태그 순서). 왜 태그 순서로 바꿨는지는 원본에 적혀 있지 않다. 이 이슈 자체에는 완료 댓글이 없어 완료 리포트는 #611 쪽에 있다.

## 근본 원인
기능 이슈. 해당 기능이 없었다(원본 「현재 문제점」 기준). 코드상 원인은 원본에 적혀 있지 않다.
