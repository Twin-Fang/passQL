# ISS-0330: 풀이 중 이전 문제 해설 시트가 남고, 빈 결과 보기가 오류처럼 보임

GitHub #538 (원본: 이슈 본문과 댓글).

## 증상
풀이 화면(오늘의 세트·챕터)에서 사용자가 확인한 문제(캡처 4장):
1. 2번을 푸는 중에 "AI 해설 · 1번 문제" 시트, 3번 중에 "AI 해설 · 2번 문제" 시트가 떠서 보기와 제출 버튼을 가린다. 해설함에서도 지난 문제 해설이 열려 섞인다.
2. 빈 결과(0행) 보기가 다른 보기의 큰 표 옆에 회색 작은 글자 한 줄로만 보여 잘못 만든 보기로 오해된다.
3. AI 해설의 "시험 팁"이 맨 아래(면책 문구 바로 위)에 있어 눈에 안 띈다.

## 재현 조건
오늘의 세트·챕터에서 해설 시트를 연 채 다음 문제로 이동.

## 조사 기록
- 2026-10-18: PR #539, #541 → 배포 PR #546, v1.24.3.
- 2026-10-26: iOS 시뮬레이터에서 "다음" 시 시트 닫힘 확인.

## 근본 원인
1은 GitHub #521 "해설 보며 계속 풀기"가 다음 문제로 가도 시트를 유지하도록 설계된 것. 2의 보기는 오류가 아니라 SQLD에서 정당한 정답 후보인 "행이 0개인 결과"였고 표시만 달랐다.
