# ISS-0326 완료 리포트: 왼쪽 로고·오른쪽 알림 종 상단 바, 환영 문구 잘림 해소

GitHub #529·#530 공동 보고 댓글(2026-10-18)과 #530 리포트 댓글(2026-10-26) 기준.

## 해결 방법
- 홈 상단: 왼쪽 passQL 로고, 오른쪽 알림 종, 환영 문구가 잘리지 않고 끝까지 표시.
- 검수 중 수정: 중요 공지 아이콘을 빨간 느낌표 대신 공통 정보 아이콘, 마크다운 본문 단어 단위 줄바꿈.
- 2026-10-26 확인: 상단 바 정상, 환영 문구 한 줄로 끝까지, 홈 종 배지 합계 3 = 알림 안 읽음 2 + 공지 안 읽음 1, "모두 읽음"은 탭별 버튼("알림 모두 읽음")으로 현재 탭만. 코드는 v1.20 이후 모든 스토어 빌드에 포함, iOS 1.51.1 심사 통과.

## 근본 원인 (확정)
이슈 노트 참조.

## 재발 방지
- 2026-10-26 확인은 화면 캡처용 가짜 API 빌드로 했다(로컬 Xcode 16.2가 결제 플러그인 0.4.13을 빌드하지 못함). 실제 서버 값 합산은 기존 단위 테스트로 보장.
- 여러 기기 크기 검수는 GitHub #646에서 이어서 본다.

## 교훈
(원본에 없음, 볼트 정리) 화면 작업은 머지 전 라이트·다크·작은 화면 캡처를 직접 보고 고치는 단계를 둔다(이슈 본문이 지적한 누락).
