# ISS-0378: 관리자 감사 로그에 동작 필터·검색이 없고 접근 이벤트가 기록되지 않는 것으로 보임

GitHub #623 (원본: 이슈 본문; 완료 내용은 GitHub #611 통합 리포트 댓글).

## 증상
감사 로그에 동작(action) 필터가 없고 대상 ID·키워드 검색이 안 된다. 대상 ID에서 해당 화면으로 갈 수 없다. 로그인·실패 로그인·권한 변경 같은 접근 이벤트가 기록되지 않는 것으로 보인다(원본 표현 그대로 '보인다').

## 재현 조건
해당 없음 (기능 이슈).

## 조사 기록
- 2026-10-24: 관리자 화면만으로 운영(DB 직접 조회 없이)하기 위한 관리자 개선 묶음(GitHub #611~#631) 중 하나로 등록. 공통 조건: 관리자 변경 작업은 기존 `AdminAuditLogService`로 감사 로그, 서버 API 변경 시 `api-contract/openapi.json` 갱신까지 한 커밋.
- 작업 범위: 동작 필터, 대상 ID·키워드·관리자 부분 일치 검색, 대상 ID에서 해당 화면 링크, 접근 이벤트 기록, 변경 내용 diff 형태 표시.
- 2026-10-24: GitHub #611 통합 구현 보고서(PR #634, 운영 배포) 결과 — 감사 로그 검색 강화, 대상 링크, 접근 이벤트 완료. 이 이슈 자체에는 완료 댓글이 없어 완료 리포트는 #611 쪽에 있다.

## 근본 원인
기능 이슈. 해당 기능이 없었다(원본 「현재 문제점」 기준). 코드상 원인은 원본에 적혀 있지 않다.
