# ISS-0319: AI 해설 형식, 품질, 속도와 해설 화면 UX 개편

GitHub #521 (원본: 이슈 본문과 댓글).

## 증상
- 정답·오답 뒤 AI 해설 뱃지가 화면과 어울리지 않고, 누르면 해설이 늦게 나온다.
- 기다리는 동안 회색 막대 로딩이 길게 남는다.
- 해설을 보는 동안 다음 문제로 넘어갈 수 없다.
- 해설 본문에 정해진 형식이 없어 읽기 어렵다.
- (검증 중 발견) 웹 모바일 390px에서 하단 피드백 바(약 300px)가 마지막 보기를 가리고 반투명 배경으로 뒤 글자가 비친다.

## 재현 조건
문제 제출 후 AI 해설 뱃지 클릭. 웹 결함은 운영 웹 데일리 세트 오답 제출 직후 390px 폭.

## 조사 기록
- 2026-10-18: 운영 웹 실측(데스크톱 2초 안 미리보기, 모바일 결함), iOS 시뮬레이터 자체 검수(시트와 미리보기 카드 중복), 개요 보고.

## 근본 원인
- 보기 4개 해설을 Gemini 4번 연속 호출로 만들었다. 세트를 만들자마자 제출하면 해설이 아직 없었다.
- 그때 배지를 누르면 요청 처리 중 생성(최대 30초 + 대기 20초), 프롬프트 버전이 바뀌면 조회 때마다 재생성.
- 해설 본문 형식이 없었다.
- 제출 시각 저장이 그 사이 저장된 해설을 옛 값으로 덮어쓸 수 있었다(바뀐 칸만 저장하도록 수정).
- 웹 하단 여백이 208px 고정값이었는데 바가 미리보기 때문에 커졌고, 배경이 10% 투명했다.
