# ISS-0363: 앱 전체 UI/UX 정리 — 화면별 검수 결과와 개선안(기기 크기 대응 포함)

GitHub #602 (원본: 이슈 본문과 댓글).

## 증상
사용자가 짚은 것(원문 요지): 바텀시트 X와 왼쪽 제목(→ GitHub #601), 풀이 결과 하단 영역 공간 부족("문제 신고는 그냥 아이콘만 있으면 되고..."), 홈 시험 일정 카드 공간, 홈 오늘의 세트 버튼 두 개, 설정 화면 모드 줄 "시스템 설정", 랜덤 닉네임 버튼(→ GitHub #579), "AI틱한 느낌", "이런 UI/UX가 한두 개가 아니다". 사용자 평가: "기기 크기와 상관없이 잘 넣어야 하는데 지금 이런 기준으로 구성을 제대로 못 해 준다".

전 화면 검수(가짜 응답 빌드 `app/tool/store_shots`, iPhone 16 Pro)에서 찾은 것 11건: 풀이 결과 하단 영역이 결과 줄·`의견 남기기`·`문제 신고`·AI 해설 카드·`다음`까지 쌓여 화면 아래 약 45%를 덮고 선택지 D가 잘림, 오늘의 세트 카드에 같은 무게 버튼 두 개, 시험 일정 카드가 옆 카드 높이에 맞춰져 빈 공간, 시트 모양 갈림, `시스템 설정`이 링크처럼 읽힘, 프로필 새로고침 아이콘 의미 불명, 문제 탭 `풀이 모드`와 MY `실전 모드` 중복, 토픽 9개 중 6개에 `최신 경향` 배지, 선택지 카드 안 코드 상자 이중 박스, 기록 화면 길이, 로그인 소셜 버튼 제각각.

## 재현 조건
해당 없음(검수 이슈).

## 조사 기록
- 2026-10-24: 로컬 iOS 시뮬레이터 빌드 실패 — Xcode 16.2(iOS SDK 18.2)에서 `in_app_purchase_storekit 0.4.13`이 `Product.PurchaseOption has no member 'introductoryOfferEligibility'`로 컴파일 안 됨(CI는 통과). 캡처 도구에 토론·의견 보내기·차단한 사용자·약관 가짜 응답이 없어 4개 화면은 검수 못 함.
- 2026-10-24: 폭 320/375/430pt × 글자 1.0/1.5/2.0배 임시 레이아웃 검사. 처음 구현본은 320pt 기본, 375pt 1.5배에서 오늘의 세트 머리가 넘침 → 완료 표시를 본문으로. main에서도 시험 일정 머리가 2배 글자에서 넘치고 있었음 → 제목 줄바꿈.
- 2026-10-24 보류 판단: #7 `풀이 모드`/`실전 모드`는 용도가 달라(연습·실전 선택 행 vs 프로 기능 켜기 스위치) 통일 대상에서 뺌. #11 로그인 버튼은 높이·모서리·정렬이 이미 같아 변경 안 함. #10 기록 길이는 줄일 근거가 화면에서 보이지 않아 변경 안 함. AI 해설 하단 패널 X는 상주 패널이라 닫기 설계가 따로 필요해 유지.
- 2026-10-24 에뮬레이터 확인 중 홈 "오늘의 세트" 제목이 좁은 카드에서 글자 중간에 줄바꿈 → PR #605.
