# ISS-0329: Android 네이버 로그인 실기기 확인과 네이버 검수 결과 반영

GitHub #537 (원본: 이슈 본문과 댓글).

취소로 닫힘: "이후 명세가 많이 바뀌어 이 이슈 내용은 지금 방향과 맞지 않아 정리합니다. 이미 반영된 부분은 다른 이슈(무료/프로 플랜 #576, 광고 #506·#522 등)로 들어갔고, 다시 필요한 기능은 지금 명세에 맞춰 새 이슈로 엽니다." (2026-10-26)

## 증상
GitHub #516에서 코드는 고쳤지만 실기기·외부 심사로만 확인할 수 있는 항목: Android 네이버 로그인 복귀(실기기, `taskAffinity=""` 제거 수정), 같은 수정이 카카오·GitHub 콜백에 영향 없는지, 네이버 로그인 검수 결과, Google·Apple 탈퇴 실측, 작은 화면·다크 모드 확인.

## 재현 조건
해당 없음 (시험 요청).

## 조사 기록
- 2026-10-18: 네이버 검수 상태 "검수요청(최종 검수 요청일 2026.10.18)", 결과 대기. Google·Apple 탈퇴 실측은 시뮬레이터를 다른 세션이 써서 중단.
- 2026-10-18: 전용 SE 시뮬레이터(`passQL-537-SE`)로 확인 — SE(375pt) 폭 주요 화면 잘림·겹침 없음, 네이버 로그인(운영)·글 작성·삭제 정상. 새 빌드에서 네이버 로그인이 "아직 준비 중인 로그인 방법"으로 나온 원인이 `.env`의 소셜 키(카카오·네이버) 누락임을 확인하고 `ENV_FILE`을 소셜 키 포함 19개 키로 갱신. Google·카카오·GitHub는 2단계 인증으로 진행 불가 → 사용자 기기 확인 필요.
- 2026-10-26: 취소.
