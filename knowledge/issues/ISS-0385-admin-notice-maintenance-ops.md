# ISS-0385: 관리자 공지는 비활성화만 되고 점검 예약·읽음률·설정 이력·푸시 연동이 없음

GitHub #630 (원본: 이슈 본문; 완료 내용은 GitHub #611 통합 리포트 댓글).

## 증상
공지는 비활성화만 가능하고 삭제·미리보기·우선순위가 없다. 점검 모드 예약(시작·종료 시각)이 없다. 읽음률(대상 대비)과 설정 변경 이력이 없고 공지 등록 시 푸시 연동이 없다.

## 재현 조건
해당 없음 (기능 이슈).

## 조사 기록
- 2026-10-24: 관리자 화면만으로 운영(DB 직접 조회 없이)하기 위한 관리자 개선 묶음(GitHub #611~#631) 중 하나로 등록. 공통 조건: 관리자 변경 작업은 기존 `AdminAuditLogService`로 감사 로그, 서버 API 변경 시 `api-contract/openapi.json` 갱신까지 한 커밋.
- 작업 범위: 공지 삭제·미리보기·정렬·우선순위·읽음률 표시, 점검 예약(시작·종료 시각), 앱 운영 설정 변경 이력, 공지 등록 시 푸시 발송 옵션.
- 2026-10-24: GitHub #611 통합 구현 보고서(PR #634, 운영 배포) 결과 — 공지 삭제·미리보기·우선순위, 점검 예약, 설정 이력 완료. 이 이슈 자체에는 완료 댓글이 없어 완료 리포트는 #611 쪽에 있다.

## 근본 원인
기능 이슈. 해당 기능이 없었다(원본 「현재 문제점」 기준). 코드상 원인은 원본에 적혀 있지 않다.
