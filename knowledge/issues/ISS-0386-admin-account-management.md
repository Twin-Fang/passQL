# ISS-0386: 관리자 계정 삭제·활동 이력 바로가기·세션 강제 종료·2FA·비밀번호 만료 정책이 없음

GitHub #631 (원본: 이슈 본문).

## 증상
관리자 계정 삭제와 계정별 활동 이력 바로가기가 없다. 세션 강제 종료, 2FA, 비밀번호 만료 정책이 없다.

## 재현 조건
해당 없음 (기능 이슈).

## 조사 기록
- 2026-10-24: 관리자 화면만으로 운영(DB 직접 조회 없이)하기 위한 관리자 개선 묶음(GitHub #611~#631) 중 하나로 등록. 공통 조건: 관리자 변경 작업은 기존 `AdminAuditLogService`로 감사 로그, 서버 API 변경 시 `api-contract/openapi.json` 갱신까지 한 커밋.
- 작업 범위: 계정 삭제(비활성화 우선 정책 유지 여부 확인), 계정별 감사 로그 바로가기, 목록 검색·정렬, 세션 강제 종료·2FA·비밀번호 변경 주기.
- 2026-10-24: GitHub #611 통합 구현 보고서(PR #634) 결과 — 일부: 계정 삭제·검색·정렬, 세션 강제 종료, 감사 로그 링크는 들어갔고 2FA와 비밀번호 변경 주기는 없음. 남은 일: 2FA(TOTP), 비밀번호 변경 주기. 이슈는 열려 있다(라벨 `작업전`).

## 근본 원인
기능 이슈. 해당 기능이 없었다(원본 「현재 문제점」 기준). 코드상 원인은 원본에 적혀 있지 않다.
