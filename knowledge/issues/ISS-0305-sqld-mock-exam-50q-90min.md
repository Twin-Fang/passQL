# ISS-0305: SQLD 실전 모의고사 (50문항 90분, 과목별 과락)

GitHub #500 (원본: 이슈 본문, 출제 경향 조사 댓글, 취소 댓글).

취소로 닫힘: "이후 명세가 많이 바뀌어 이 이슈 내용은 지금 방향과 맞지 않아 정리합니다. 이미 반영된 부분은 다른 이슈(무료/프로 플랜 #576, 광고 #506·#522 등)로 들어갔고, 다시 필요한 기능은 지금 명세에 맞춰 새 이슈로 엽니다." (2026-10-26)

## 증상
지금은 무작위 10문제 연습 세션(GitHub #305 미니 모의고사)만 있고, 실제 SQLD처럼 시간 제한과 과목 배분이 있는 실전 연습이 없다.

## 재현 조건
해당 없음(기능 추가 제안).

## 조사 기록
- 2026-10-16 제안 내용(구현되지 않음): 50문항·90분, 1과목 10·2과목 40, 60점 합격·과목별 40% 미만 과락, 남은 시간·문항 번호판·표시·일괄 제출·자동 제출·이어 풀기, 결과(과목별 점수·과락, 미리 생성된 해설), 회차별 점수 추이. 출제는 이미 만든 재사용 선택지 세트에서만(원본 이유: 50문제를 실시간 AI로 만들면 느리고 비싸다). 등급별 응시 횟수(기본 주 1회, Pro 무제한)는 크레딧 전제.
- 2026-10-16 출제 경향 조사 댓글(56~62회, 네이버 카페 2곳 47개 글과 dataq.or.kr 공식 안내 기준, 2026-10-16 확인):
  - 공식 형식: 객관식 50문항만, 1과목 데이터 모델링 10문항×2점, 2과목 SQL 40문항×2점, 90분, 총점 60점 이상 합격, 과목별 40% 미만 과락(1과목 8점 미만). 공식 범위에 옵티마이저·실행계획·인덱스는 없다. 2026년 63회 시험일 11.14(토). 2027년 일정과 회차별 합격률은 미확인.
  - 체감 난이도: 58회(2025.8)부터 한 단계 올라갔고 이후 회차마다 오르내림. 어려운 회차의 공통점은 두 선지 사이에서 헷갈리는 문제, 시간 압박, 1과목이 당락을 가름.
  - 자주 나온 주제: 1과목 식별자·정규화·엔터티 분류·속성, 2과목 NULL 처리·공집합 vs 0 vs NULL·조인·그룹 함수·윈도우 함수·계층형 질의·PIVOT·정규 표현식. 2과목은 쿼리 실행 결과 맞히기가 중심(62회 후기 "90%가 쿼리 해석").
  - passQL 시사점(원본 제안): 현재 topic 9개에 집합 연산자·정규 표현식·DCL·TOP-N이 따로 없음, 교차 태그 `null_empty_set` 제안, 모의고사 2과목 영역별 문항 배분표, 유형 비율, 난이도 L1~L4, 문제 작성 규칙(한글 식별자 섞기, NULL 행 넣기, 실제 실행 결과로 검증, 복원 문제 원문 사용 금지).
  - 원본 표기: 일부 수치(2과목 출제 비중)는 후기 빈도에서 추정한 값이며 공식 수치가 아니다.
