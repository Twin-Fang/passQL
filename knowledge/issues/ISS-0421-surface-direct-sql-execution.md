# ISS-0421: 직접 실행 경험 드러내기 — 실행 버튼·결과 비교·실습 칸·입력 보조

GitHub #727 (원본: 이슈 본문과 댓글).

## 증상
- 실행형 문제에서 보기를 누르면 로딩 후 "보기 B · 실행 성공" 카드만 뜨고 실행한다는 안내·버튼이 없다. GitHub #607에서 "▶ SQL 실행" 배지를 "실행 결과 문제"(표 아이콘)로 바꾼 뒤 "실행" 표시가 하나도 남지 않았다.
- 앱에는 내 SQL을 입력해 실행하는 칸이 처음부터 없었다(웹 `client/src/components/SqlPlayground.tsx`에만, 실행형 문제에서만, 빈 칸 시작).
- 운영 활성 문제 기준 실행형(`EXECUTABLE`) 48(16%), 개념형(`CONCEPT_ONLY`) 261(84%, 그중 관리자 Oracle 문제 212). 관리자 Oracle 문제는 PostgreSQL 샌드박스와 결과가 다를 수 있어 실행하지 않는다.
- 휴대폰으로 괄호·따옴표·비교 기호 입력이 번거롭다.

## 재현 조건
앱 실행형 문제 풀이.

## 조사 기록
- 이슈 본문 구상안 A~G(보기별 실행 버튼, 내 답 vs 정답 비교, 실습 칸, 전용 실습 화면, Oracle 실행 기록, 값만 바꾸기 칩, 입력 보조 막대)와 제안 조합(확정 전): 1단계 실행형 48문제 A+B+C(F 기본, G 전환), 2단계 E, 실행형 전환 별도 검토.
- 2026-10-28 1차 시뮬레이터 실측과 수정(`bc0017e0`): 함수 칩 뒤 커서가 괄호 안에 남음 → 커서 이동 칩·닫는 괄호 칩, 공백 두 번 → 기호 앞 공백 생략, 결과 카드 이중 들여쓰기 제거.
- 2026-10-28 2차 변경(`be04925a` 앱, `5372f597` 서버): 보기 실행은 제출 뒤에만, 고치기 시트 배치 변경, 샌드박스 공유 캐시.
- 참고: Xcode 27.1 시뮬레이터 빌드에서 Pod 최소 iOS 버전(9~13) 오류와 Flutter 아키텍처 검사 오류. Podfile 임시 수정으로 실측 후 되돌림(범위 밖).

## 근본 원인
실행을 드러내는 UI와 실습 칸 부재(이슈 본문).
