# ISS-0243: 선택된 시험 일정이 지난 제61회로 남아 홈 D-day가 D+로 표시

GitHub #411 (원본: 이슈 본문과 댓글 3개).

## 증상
관리자 > 시험 일정에서 "선택"된 회차가 이미 지난 제61회(2026-05-31). 제62회(08-22)도 지났고 다음은 제63회(2026-11-14). 웹 홈 D-day 카드는 지난 시험이면 `D+N`을 그대로 표시 → "제61회 D+130"이 보이는 상태로 추정(로그인 후 화면은 직접 확인 못 함, 코드 `Home.tsx` D-day 계산으로 판단).

## 재현 조건
운영(v0.0.247, 2026-10-08). 관리자 로그인 → 시험 일정 → 선택 열 / 웹 로그인 → 홈 시험 카드.

## 조사 기록
- 2026-10-08: 운영 조치 — 선택 회차를 제61회 → 제63회(2026-11-14)로 변경, 홈 D-day `D-37` 기준. 공식 일정(데이터자격검정)과 2026년 제60~63회 날짜가 운영 DB와 일치.
- 2026-10-08: 2027년 일정은 공고 전. 매년 날짜가 바뀌어 자동 추가는 하지 않는다. 공고 대기로 `작업중` 유지.
- 2026-10-08: 재발 방지 기능(공식 공고 확인 패널·대시보드 경고) v0.5.0(PR #444) 배포.
- 2026-10-16: 완료 처리.

## 근본 원인
선택 회차를 바꾸는 운영 작업이 빠졌고, 지난 회차·다음 회차 미등록을 알려 주는 장치가 없었다.
