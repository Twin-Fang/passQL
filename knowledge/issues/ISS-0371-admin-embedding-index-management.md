# ISS-0371: 관리자 임베딩 색인 관리 — 재색인이 동기 호출이라 진행률이 없고 실패 재시도·이력이 없음

GitHub #616 (원본: 이슈 본문; 완료 내용은 GitHub #611 통합 리포트 댓글).

## 증상
미색인 목록이 UUID만 보여 식별이 어렵다. 전체 재색인이 동기 호출이라 진행률이 없고 대량 시 타임아웃 위험이 있다. 색인 실패 목록·재시도·실행 이력이 없다.

## 재현 조건
해당 없음 (기능 이슈).

## 조사 기록
- 2026-10-24: 관리자 화면만으로 운영(DB 직접 조회 없이)하기 위한 관리자 개선 묶음(GitHub #611~#631) 중 하나로 등록. 공통 조건: 관리자 변경 작업은 기존 `AdminAuditLogService`로 감사 로그, 서버 API 변경 시 `api-contract/openapi.json` 갱신까지 한 커밋.
- 작업 범위: 미색인 목록에 지문 미리보기·토픽 표시, 재색인 비동기화와 진행률, 실패 목록과 재시도, 마지막 실행 시각·이력.
- 2026-10-24: GitHub #611 통합 구현 보고서(PR #634, 운영 배포) 결과 — 임베딩 미리보기, 비동기 재색인과 진행률, 실패 재시도, 이력 완료. 이 이슈 자체에는 완료 댓글이 없어 완료 리포트는 #611 쪽에 있다.
- 주의(#611 리포트): 임베딩 진행률은 서버 메모리 한 건에 저장한다. 재시작하면 사라지고 DB의 RUNNING 기록은 다음 실행 때 FAILED로 정리된다.
- 통합 중: 이 영역이 추가한 감사 대상 `EMBEDDING_INDEX`가 다른 영역의 경로 매핑 switch에 빠져 컴파일이 깨졌고 임베딩 화면 경로를 추가해 해결.

## 근본 원인
기능 이슈. 해당 기능이 없었다(원본 「현재 문제점」 기준). 코드상 원인은 원본에 적혀 있지 않다.
