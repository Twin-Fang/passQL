# ISS-0307: 앱 품질 고도화 로드맵 (모션, AI 해설, 성능, 크레딧, 광고, 모의고사)

GitHub #502 (원본: 이슈 본문과 댓글).

취소로 닫힘: "이후 명세가 많이 바뀌어 이 이슈 내용은 지금 방향과 맞지 않아 정리합니다. 이미 반영된 부분은 다른 이슈(무료/프로 플랜 #576, 광고 #506·#522 등)로 들어갔고, 다시 필요한 기능은 지금 명세에 맞춰 새 이슈로 엽니다." (2026-10-26)

## 증상
본문이 적은 현재 문제점:
- 제품 방향: 듀오링고처럼 매일 조금씩 이어서 푸는 SQLD 공부 앱. 매일 돌아오고 싶게 만드는 경험을 기준으로 판단.
- 최근 SQLD 난이도가 올라 문제·모의고사가 실제 경향을 따라가야 한다.
- 앱이 딱딱하고 밋밋하다(연출, 태그, AI 화면). AI 해설은 매번 기다려야 하고 저장되지 않는다. 로딩이 느린 화면이 있다.
- 수익 모델(Pro, 크레딧, 광고)과 실전 모의고사가 없다.

진행 순서 체크리스트(닫힐 때 상태): 완료 GitHub #503, #495, #496, #497 / 미완료 #498(등급·크레딧), #499(광고, 배너·네이티브·전면은 #506으로 반영되고 보상형·크레딧 연동 남음), #504, #500(모의고사), #501, #509.

본문의 "결정 사항"(취소된 로드맵의 계획): 카페 후기로 출제 경향 조사, 복원 문제 원문은 저작권 문제로 옮기지 않고 같은 스타일로 새 문제 생성 / Pro는 관리자 부여까지, 인앱 결제는 #501 / 크레딧은 AI 심화 해설·모의고사 추가 응시에만, 기본 해설은 무료 / 크레딧 충전: 매일 무료·보상형 광고·관리자·구매 / 광고는 보상형과 홈·문제 목록 하단 배너만, Pro에게 숨김 / 앱 심사 제출은 별도 요청 시에만.
