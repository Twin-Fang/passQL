# ISS-0215: QA 관찰 사항 — 이탈 확인·세트 재진입 결과·신규 준비도 등 개선 후보

GitHub #370 (원본: 이슈 본문과 댓글).

## 증상
QA GitHub #357 진행 중 발견한 개선 후보:
1. 풀이 도중 홈 아이콘을 누르면 확인 없이 나가져 진행 중이던 챕터 풀이가 사라짐
2. 완료한 오늘의 세트 재진입 화면에 "문제별 결과"가 없음(완료 직후 화면에는 있음)
3. 신규 가입 직후 합격 준비도 카드: 푼 문제 0개인데 정확도 0%, 범위 0/9, 최신성 70%
4. 탭을 옮겼다 돌아오면 목록 스크롤 위치 초기화
5. 건의사항 입력창이 500자를 넘겨도 입력이 계속됨(카운터 550/500 빨간색, 전송 버튼 비활성이라 동작은 안전)
