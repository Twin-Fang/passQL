# ISS-0350: 공개 문제 전수 점검 — 보기 중복, 바로 지워지는 오답, 숫자 보기 순서

GitHub #565 (원본: 이슈 본문과 댓글).

## 증상
GitHub #555로 새로 들어오는 보기 세트는 중복 차단·숫자 순서 점검이 되지만, 이미 공개된 문제에는 같은 내용 보기(2026-10-20 오늘의 세트 6번 B·C), 바로 지워지는 오답(1번 "결과 없음 · 0행"), 숫자 보기 순서 섞임(8번 1, 3, 4, 2)이 남아 있을 수 있다.

## 재현 조건
해당 없음(전수 점검 이슈).

## 조사 기록
- 2026-10-21 운영 DB 읽기 전용 점검:
  - 같은 내용 보기: 1세트, 단 회원 한 명용 재사용 안 하는 AI 세트(2026-05)이고 해당 문제는 고정 보기 세트로 출제 → 출제 영향 0.
  - 6번(B·C 동일, 세트 17543dea): 실제로 동일, 문제는 이미 비활성(GitHub #548 감사 때).
  - 빈 결과 보기: 활성 문제의 출제용 세트에 `[]` 보기 0건.
  - 숫자 보기 순서: 서버가 고정 보기 표시 순서를 무작위로 섞어서 생김(GitHub #512).

## 근본 원인
숫자 보기 순서는 서버 보기 섞기 때문. 나머지 두 결함은 활성 문제에 없었다.
