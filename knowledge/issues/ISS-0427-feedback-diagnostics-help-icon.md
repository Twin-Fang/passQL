# ISS-0427: 의견 보내기의 진단 정보 안내 글자 버튼을 `?` 아이콘으로 바꾸기

GitHub #744 (원본: 이슈 본문. 댓글 없음, 2026-10-28 완료로 닫힘).

## 증상
설정 > 의견 보내기의 "진단 정보 같이 보내기" 줄 오른쪽에 "포함되는 정보 보기" 글자 버튼이 있다. 줄이 길어지고 체크박스 라벨과 경쟁한다.

제안(이슈 본문):
- 글자 버튼을 `?` 아이콘(물음표 원) 버튼으로 바꾼다. 누르면 지금처럼 포함되는 정보 시트를 연다.
- 화면 읽기 프로그램용 이름은 "포함되는 정보 보기"로 유지하고, 터치 영역은 최소 크기를 지킨다.
- 작업 파일: `app/lib/presentation/widgets/feedback/feedback_diagnostics_check_row.dart`

## 재현 조건
해당 없음 (기능 개선). 앱 설정 > 의견 보내기 화면에서 보인다.

## 조사 기록
- 2026-10-28: 이슈 등록, 같은 날 완료로 닫힘. 구현·검증 내용은 원본에 적혀 있지 않다.

## 근본 원인
원본에 적혀 있지 않다 (기능 개선 이슈로, 현재 문제점은 위 증상 참고). 완료 리포트나 완료 댓글이 없어 리포트 노트를 만들지 않았다.
