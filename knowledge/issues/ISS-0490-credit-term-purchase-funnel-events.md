# ISS-0490: 구매·광고 흐름 분석 이벤트 추가와 겹치는 정보 정리 (크레딧)

GitHub #971.

## 증상
- 이용권 구매 흐름과 광고 보너스 흐름에 분석 이벤트가 없어 어디서 빠지는지 볼 수 없음.
- "오늘 남은 문제", "문제 더 받기", "+5문제" 등 같은 것을 가리키는 말이 여럿이고 여러 곳에 겹쳐 보임.
- 랜덤 풀이 상단에 `N번째 문제`, `오늘 남은 N문제`, `랜덤 풀기` 칩이 한꺼번에 나옴.
- 탭 화면(개념·문제·토론) 제목이 큰 제목 줄로 내려가 오른쪽 요소와 줄이 안 맞음.
- 보기 방식 이름 `검증된 보기` 가 `AI 새 보기` 보다 좋아 보임.

## 재현 조건
결제 켜짐 + 무료 회원 (탭 제목 정렬은 모든 회원).

## 조사 기록
- 2026-11-12: `AppAnalytics` 에 구매·광고 이벤트 없음 확인. 다른 앱(ELUM)의 크레딧 표현(반짝임 + 큰 숫자 + 막대)을 참고.
- 2026-11-12: 홈 합격 준비도 링 개선은 따로 떼어 GitHub #972 로 남김.

## 근본 원인
결제를 켠 뒤 구매·광고 단계 로그가 없었고, 한도·보상을 가리키는 말과 표시가 화면마다 달랐다.
