# ISS-0356: 홈, 문제 탭 재구성 — 출제 경향 분리 및 오답 노트 이동 (이후 앱 전체 발견성·접근성 개편으로 확장)

GitHub #574 (원본: 이슈 본문과 댓글).

## 증상
기능 이슈. 현재 문제점:
- 기능은 많은데 찾기 어렵다.
- 홈의 '2026 SQLD 출제 경향'이 한 줄짜리 작은 카드뿐이고, 그 안에 요약·과목 비중·늘어난 유형 8개·자주 나오는 개념 TOP 10·공부 팁 7개가 화면 하나에 몰려 있다.
- 최신 경향 문제가 몇 개 어디에 반영됐는지 숫자로 보이지 않는다.
- 오답 노트가 설정 탭 '기록' 묶음 안에 숨어 있다.
- 2026-10-21 범위 확장: 하단 탭이 아이콘만이라 의미를 추측해야 함, 실전 모드가 설정 깊이 숨음, 홈 '일정 선택하기'가 눌리지 않음, 결과·풀이 나가기가 항상 홈으로(10곳), 스크린리더로 누를 수 없는 버튼·이중 낭독·대비 부족.

## 재현 조건
해당 없음.

## 조사 기록
- 2026-10-21: 1차 범위(출제 경향 분리·오답 노트 이동) 구현, 시뮬레이터 라이트/다크 캡처.
- 2026-10-21: 사용자 요청으로 앱 전체 기능 발견성·접근성 개편으로 확장. 시작 전 점검 2종 — 기능 진입 경로(기능 전수 목록·묻힌 기능 TOP 10), 접근성(Critical 4·Important 9).
- 2026-10-22: 홈 출제 경향을 넘김 카드로 바꾸는 마지막 수정(`c447dc56`), main 병합(PR #583), GitHub #576 결제(PR #582)와 충돌 12개 정리, deploy #584.

## 근본 원인
화면별 역할 구분 없이 기능이 쌓였고, 접근성은 화면마다 따로 처리돼 공통 지점이 없었다.
