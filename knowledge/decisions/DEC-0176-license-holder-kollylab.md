# DEC-0176: `LICENSE` 저작권자·Licensor는 `KOLLYLAB (콜리랩)`, 문의 연락처는 운영자 이메일 하나, 사업자 식별 정보는 공개 레포에 넣지 않는다

GitHub #638 (원본: 이슈 본문 「작업」과 완료 리포트).

## 문제 정의 (Context)
수익화를 위해 사업자(콜리랩, KOLLYLAB)를 등록했는데 `LICENSE`와 README는 해커톤 시절 팀 이름(passQL-Lab)과 이전 공동 작업자 연락처를 가리켰다. 공동 작업자와의 권리 합의는 사용자가 이미 받은 것으로 확인했다.

## 결정 (Decision)
- `LICENSE` 저작권자와 `Licensor`를 "KOLLYLAB (콜리랩)"으로 한다.
- `LICENSE`·`README.md`의 라이선스 문의 연락처는 현재 운영자 이메일 하나로 통일한다.
- 사업자등록번호·대표자 개인정보는 공개 레포에 넣지 않는다.
- 라이선스 조항 본문(상업 이용·서비스 운영·배포 금지)은 바꾸지 않는다.

## 검토한 대안 (Alternatives)
논의 기록 없음.

## 결과 (Consequences)
**긍정**
- 논의 기록 없음.

**부정**
- 논의 기록 없음.

## 영향 범위 (Scope)
저장소 루트 `LICENSE`, `README.md`. (리포트가 남긴 확인 대상: 앱 이용약관·개인정보처리방침의 운영 주체 표기, 스토어 개발자 이름.)
