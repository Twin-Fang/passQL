# DEC-0191: 앱 홈 순서는 합격 준비도(내 상태) → 오늘의 세트(행동) → 출제 경향 → 추천 → 학습 현황 → 광고 → 공부 팁 → 토론

## 문제 정의 (Context)
홈을 열었을 때 지금 해야 할 일이 먼저 보여야 했고, 오늘의 세트 버튼 위치를 정해야 했다 (GitHub #701 리포트 결정 기록 3).

## 결정 (Decision)
- 첫 구간: 인사말 > 공지 > 합격 준비도. 다음 오늘의 세트(버튼이 첫 화면 중간 아래, 엄지 자리).
- 이어서 이번 시험 출제 경향(세트 바로 아래, 구간 면 없이 회색 바탕), 추천 문제(최대 3개, 「더 보기」), 학습 현황(5주 달력), 광고, 오늘의 공부 팁, 오늘의 토론.
- 오늘의 순위는 별도 행이 아니라 세트 제목 줄 오른쪽 「순위 ›」 링크. 연속 학습 일수 표시와 준비도 제목은 뺀다(확정 댓글).

## 검토한 대안 (Alternatives)
리포트 결정 기록 3:
- 세트를 맨 위: 기록 없는 사람에게 빈 링이 먼저 보이는 걱정은 안내 문구로 해결하고 준비도를 위에 둠.
- 출제 경향을 맨 위: 버튼이 첫 화면 밖으로 밀리고 강조가 둘이 되어 버림.
처음 시안에서는 준비도가 세트 아래, 출제 경향이 광고 아래였다(확정 댓글 「처음 시안과 달라진 점」).

## 결과 (Consequences)
**긍정**
- 논의 기록 없음 (측정 결과 없음).

**부정**
- 인사말이 두 줄이 되는 날은 버튼이 더 내려간다(결정 기록 3).
- (원본에 없음, 볼트 정리) 추천 문제가 맨 아래에서 위로 올라왔다. GitHub #676 리포트는 추천 섹션을 위로 옮기면 늦게 붙을 때 아래 카드가 밀려 자리 잡기 처리가 필요하다고 적었다 — #701 원본은 이 점을 언급하지 않는다.

## 영향 범위 (Scope)
`app/lib/presentation/pages/home/home_page.dart`, `widgets/home/` 구간 위젯들.
