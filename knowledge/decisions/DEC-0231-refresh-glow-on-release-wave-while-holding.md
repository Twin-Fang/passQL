# DEC-0231: 새로고침 물결은 끝까지 당긴 뒤 손 뗄 때까지 반복하고, 빛은 손을 떼는 순간 화면 끝까지 번진다

## 문제 정의 (Context)
새로고침 빛과 물결을 언제 시작하고 멈출지 정해야 했다 (GitHub #772). 당기는 도중에 빛이 나오면 어색했고, 손을 뗀 뒤 띠가 줄어들 때까지 기다리면 반응이 늦었다. 빠른 응답이면 손 떼기 전에 새로고침이 끝나 물결이 멈췄고, 띠가 접히면 빛이 중간에 끊기거나 화면 끝에 닿기 전에 사라졌다.

## 결정 (Decision)
- **당기는 중:** 당긴 만큼 점이 켜진다.
- **끝까지(놓으면 새로고침되는 지점) 당겼을 때:** 가벼운 진동이 한 번 오고, 손을 뗄 때까지 물결이 반복된다. 손 떼기 전에 새로고침이 끝나도 잡고 있는 동안은 물결이 계속된다.
- **손을 떼는 순간:** 빛이 시작된다. 새로고침 상태로는 띠가 줄어든 뒤에야 알 수 있어서, 전역 포인터 손 뗌을 직접 받는다.
- **다시 불러오는 동안:** 주기마다 새 빛을 띄운다. 끝나면 새 빛만 멈추고, 이미 번지던 빛은 끝까지 간다.
- **빛 한 번의 수명:** 스스로 끝까지 퍼진 뒤 걷힌다. 띠가 먼저 접혀 표시 위젯이 사라져도 끊기지 않는다.
- **빛의 모양 (`PassqlGlow` 공통, 개념 점수판 빛도 같이 바뀜):**
  - 가장 밝은 고리가 화면에서 가장 먼 귀퉁이에 닿도록 빛을 키운다.
  - 고리가 끝에 닿을 때까지 진하게 버티다가 마지막에 옅어진다.
- **빛 한 번 퍼지는 시간:**
  - 700·800·900ms를 손 떼는 시점을 맞춰 나란히 녹화해 비교했고, 사용자가 800ms를 골랐다.
  - 값 원본은 `PassqlMotion.refreshGlowLoop`다.
  - 개념 점수판 빛 시간(`conceptGlowSpread`)과는 따로 둔다.
- **물결 한 주기:** `PassqlMotion.refreshWaveLoop`. 사용자가 직접 조정했다.

## 검토한 대안 (Alternatives)
- 끝까지 당기는 순간(armed) 빛과 물결을 같이 시작하기: 사용자가 "댕기고 나오는 게 아니라 리로딩 되면 파동 나오게"라고 했다.
- 새로고침 상태(띠가 제자리로 줄어든 뒤)에서 빛 시작하기: 사용자가 "pull에서 손을 뗐을 때 파동이 나오게"라고 했다.
- 새로고침이 끝나면 물결 멈추기: 사용자가 "pull 계속 댕겨놓고 안 놓으면 물결 애니메이션 계속 반복되어야지"라고 했다.
- 빛을 표시 위젯이 가진 애니메이션 하나로 반복하기: 띠가 접히며 위젯이 사라질 때 빛도 지워져 끊겼다. 빛을 한 번씩 스스로 끝나는 층으로 바꿨다.
- 퍼지는 내내 고르게 옅어지기: 끝에서 안 보여서 사용자가 "파동이 끝까지 가야 함"이라고 했다.
- 빛 시간:
  - 1400ms에서 사용자가 "속도 조금 더"라고 해 1100ms로 바꿨다.
  - 이후 사용자가 직접 800ms로 바꿨고, 700·800·900ms 비교 뒤 800ms로 확정했다.

## 결과 (Consequences)
**긍정**
- 손을 떼면 바로 빛이 나오고, 빛이 화면 끝까지 보인다.
- 응답이 빨라도 손 뗌에 빛이 한 번은 나온다.

**부정**
- 손 뗌을 전역 포인터 경로로 받기 때문에, 두 손가락으로 당기다 하나만 떼도 빛이 미리 나올 수 있다.
- 빛이 끝까지 진하게 버티는 만큼, 화면이 연보라로 물든 시간이 조금 길어졌다.
- 개념 점수판 빛 모양도 같이 바뀌었다. 구현 세션에서 점수판 화면은 시뮬레이터로 직접 확인하지 못했다.

## 영향 범위 (Scope)
`app/lib/presentation/design/components/passql_refresh_control.dart`(손 뗌 감지, 물결·빛 시작과 멈춤, 한 번씩 끝나는 빛 층), `passql_glow.dart`(앞머리 도달 반지름, 옅어지는 곡선), `tokens/passql_motion.dart`(`refreshGlowLoop`, `refreshWaveLoop`).
