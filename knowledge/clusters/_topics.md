# Topic Vocabulary (통제 어휘)

클러스터링 일관성의 기준 파일. 노트에 topic을 붙이기 전 반드시 이 목록을 먼저 확인하고,
의미가 겹치면 기존 슬러그를 재사용한다. 새 슬러그는 아래에 한 줄 정의와 함께 추가한다.

형식: `slug` — 정의

<!-- 프로젝트 시작 시 비어 있음. /ingest-meeting 이 자동으로 채워나감. -->

- `billing` — 결제·요금제·이용권·무료/프로 등급 판정과 스토어(Play·App Store) 연동
- `security` — 인증·CSRF·토큰·민감 정보 노출 등 보안 문제와 대책
- `admin` — 관리자 화면(Thymeleaf)과 관리자 API
- `ai` — AI 서버·LLM 호출·선택지 생성·해설·프롬프트·임베딩
- `practice` — 문제 풀이·제출·실행 결과·오늘의 세트·데일리 챌린지·실전 모드
- `question-bank` — 문제 등록·품질·검증·신고·토픽·난이도
- `concept-learning` — 개념 학습·단원
- `home` — 홈 화면·추천
- `progress-stats` — 통계·합격 준비도·학습 현황·순위
- `community` — 토론·의견·건의·커뮤니티
- `auth-member` — 로그인·회원가입·탈퇴·온보딩·프로필
- `notification` — 푸시·알림
- `ads` — 광고
- `design-system` — 디자인 토큰·공통 UI 컴포넌트·폰트·테마
- `ci-deploy` — CI/CD·배포·버전 관리·빌드
- `store-release` — 스토어 심사·출시·스토어 문구·법적 고지
- `ops-infra` — 운영 서버·로그·모니터링·DB·Flyway·인프라·성능
- `dev-workflow` — 개발 도구·projectops·테스트 정책·문서·API 계약
