# passQL 앱 PRD

> 갱신: 2026-10-07 | 대상: Flutter 앱 (Android/iOS, 한국)

## 1. 서비스 개요

passQL은 SQLD·SQLP 자격증 준비를 위한 SQL 학습 앱이다. 회원은 **Google 또는 Apple 계정으로 로그인**하고,
문제 풀이 → 채점·해설 → 통계·오답 노트 확인의 학습 루프를 반복한다.

## 2. 핵심 화면

| 탭/화면 | 내용 |
|---|---|
| 홈 | 인사말, 오늘의 세트(매일 10문제), 시험 일정 D-day, 합격 준비도, 학습 현황(히트맵), 추천 문제 |
| 문제 | 토픽 목록 → 챕터(문제 목록) → 문제 상세(선택지 생성·SQL 실행·제출) |
| 통계 | 풀이 수·정답률·연속 학습, AI 영역 분석, 토픽별 레이더 차트 |
| 설정 | 프로필(닉네임 변경·랜덤), 오답 노트, 실전 모드, 건의사항, 이용약관, 개인정보처리방침, 로그아웃, 회원 탈퇴 |
| 오늘의 세트 | 전 회원 동일 문제, 결과, 리더보드(서버가 제출 기록으로 점수 검증) |
| 로그인 | Google/Apple 버튼(약관 동의 안내) |

## 3. 인증

- Firebase로 소셜 인증 후 서버 `POST /auth/login`에 idToken을 보내 JWT(access/refresh)를 받는다.
- 이후 모든 요청은 `Authorization: Bearer`. 만료 시 refresh로 재발급, 실패하면 로그인 화면으로 이동.
- 회원 탈퇴는 계정·개인정보 삭제와 Apple 토큰 회수를 포함한다 (스토어 심사 필수).

## 4. 학습 기능

- **선택지 생성**: 서버 SSE로 AI/검증된 선택지를 받는다. 실전 모드를 켜면 매번 AI가 새로 만든다.
- **실행형 문제**: 선택지 SQL을 서버 샌드박스(PostgreSQL)에서 실행해 결과를 비교한다.
- **오답 노트**: 틀린 문제 목록에서 바로 다시 풀 수 있다.
- **문제 신고·건의사항**: 문제 신고 시트, 건의사항 작성과 처리 상태 확인.

## 5. 비기능

- 서버와만 통신한다 (AI 서버 직접 호출 금지). 운영 API `https://api.passql.suhsaechan.kr/api`.
- 오류는 `ErrorCode`/`AppException`으로 사용자 문구로 변환한다.
- 개인정보처리방침·이용약관·계정 삭제 안내는 공개 웹 페이지(`passql.vercel.app/legal/...`)로 제공한다.
- 스토어: App Store(iOS), Google Play(Android). 출시 진행은 GitHub 이슈 참고.
