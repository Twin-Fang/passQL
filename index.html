check_circle제58~62회 복원 기출과 수험생 후기·오픈채팅 분석

짧은 쿼리에 NULL 함정을 숨기고 결과를 따라가게 하는 문제가 중심이에요. 62회는 쉬웠다는 말이 많았지만 합격률은 낮았어요.

1과목 데이터 모델링의 이해20%

정의 암기보다 참여도·상호배타·다중값 속성을 지문 상황에 적용하는 문제가 늘었어요.

2과목 SQL 기본과 활용80%

대부분이 결과 행 수·값·오류 여부를 직접 계산하는 추적형이에요.

  • trending_up늘어난 유형 · 62회 집중 출제

    짧은 쿼리 속 NULL 함정

    NOT IN, 빈 결과 집계, NULL 비교, NULL 치환 함수를 섞어 결과를 바꿔요.

  • trending_up늘어난 유형 · 61·62회

    결과 비교형 보기

    보기마다 SQL을 주고 결과 행 수가 가장 많은 것, 결과가 다른 것을 골라요.

  • trending_up늘어난 유형 · 58·61·62회

    오류 나는 SQL 고르기

    인라인 뷰 별칭을 바깥에서 쓰거나 스칼라 서브쿼리가 여러 행을 돌려주는 SQL을 찾아요.

  • trending_up늘어난 유형 · 61·62회

    ROWNUM 실행 순서

    ROWNUM이 ORDER BY보다 먼저 붙는 점과 부등 조건에서 행이 탈락하는 점을 노려요.

자주 묻는 질문

passQL은 무료인가요?expand_more

네, 무료로 내려받아 바로 시작할 수 있고 지금은 SQL 실행, 보기별 AI 해설, 최신 출제 경향까지 모든 기능이 열려 있어요. 나중에 Pro 이용권(1개월·3개월, 자동 결제 없음)이 생기면 무료로는 하루 일정량을 풀 수 있어요.

SQLD 시험 범위를 모두 다루나요?expand_more

SQLD 두 과목의 범위를 9개 주제로 나눠 문제를 제공해요. 1과목 데이터 모델링, 2과목 SELECT·DDL/DML/TCL·함수·JOIN·서브쿼리·그룹함수·윈도우 함수·계층과 PIVOT이에요.

최신 출제 경향은 어떻게 반영하나요?expand_more

제58~62회 복원 기출과 수험생 후기를 분석해 과목별 비중, 최근 늘어난 유형, 자주 나오는 개념 TOP 10을 정리했어요. '최신 경향' 표시가 붙은 문제부터 골라 풀 수 있어요.

하루에 얼마나 공부하면 되나요?expand_more

매일 열리는 오늘의 세트 5문제가 기본이에요. 여유가 있으면 약한 주제와 오답 노트를 더 풀고, 합격 준비도로 남은 부분을 확인하세요.

SQLP도 준비할 수 있나요?expand_more

SQLP 필기의 데이터 모델링, SQL 기본 및 활용 과목은 SQLD와 범위가 겹쳐 그대로 연습할 수 있어요. SQL 고급 활용 및 튜닝 과목과 실기는 아직 다루지 않아요.

앱을 설치하지 않고 쓸 수 있나요?expand_more

네. passql.vercel.app 에서 로그인하면 앱과 같은 학습 기록으로 이어서 풀 수 있어요.

Android에서도 쓸 수 있나요?expand_more

네. Google Play에서 passQL을 내려받을 수 있어요. iPhone은 App Store, PC는 웹에서 같은 계정으로 이어서 풀 수 있어요.

개념 공부도 앱에서 할 수 있나요?expand_more

네. 단원마다 꼭 기억할 것, 자세한 설명, 확인 문제를 순서대로 볼 수 있어요. 개념을 읽고 바로 문제로 확인해요.
